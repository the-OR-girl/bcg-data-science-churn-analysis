# BCG Data Science Job Simulation – Customer Churn Analysis

## Overview

Completed a customer churn analysis project as part of the BCG Data Science Job Simulation on Forage.

The project focused on understanding customer churn, engineering relevant features, building a Random Forest classification model, and translating model results into actionable business insights.

## Project Workflow

- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Transformation
- Random Forest Classification
- Model Evaluation
- Business Insights and Recommendations

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Model Performance

| Metric | Score |
|---|---:|
| Accuracy | 90.59% |
| Precision | 54.64% |
| Recall | 18.66% |
| F1 Score | 27.82% |
| ROC-AUC | 69.42% |

## Key Takeaway

While the model achieved high overall accuracy, recall was substantially lower. This highlights why accuracy alone is not sufficient for a customer churn problem, where identifying actual churners is particularly important.

The analysis demonstrates the importance of selecting appropriate evaluation metrics and translating model performance into meaningful business decisions.
